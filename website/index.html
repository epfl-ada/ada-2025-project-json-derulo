2. The Long Haul: Duration of Study

How long does this degree program generally take to complete? Is it a quick joke or a long setup?


# converting each semester to numeric index: Spring=0, Fall=0.5
df['semester_numeric'] = df['semester'].map({'Spring': 0, 'Fall': 0.5}).astype(float)
df['semester_index'] = df['year'] + df['semester_numeric']

# Group by student to get first and last semester
enrollment_span = df.groupby('student_id')['semester_index'].agg(['min','max']).reset_index()

# Compute enrollment duration
enrollment_span['total_sem'] = ((enrollment_span['max'] - enrollment_span['min']) / 0.5 + 1).astype(int)
enrollment_span['total_years'] = enrollment_span['total_sem'] / 2
enrollment_span['total_years_rounded'] = enrollment_span['total_years'].apply(math.ceil)

avg_duration = enrollment_span['total_years'].mean()
rounded_avg_duration = math.ceil(avg_duration)
print("Average duration across all students:", avg_duration, "years")
print("Rounded up average time to complete the degree program:", rounded_avg_duration, "years")

The average enrollment duration is 1.86 years. When rounded up, this degree program generally takes 2 years to complete.

3. Identity Crisis: Formatting Student IDs

Each student ID is supposed to be exactly 8 characters long. However, data gremlins often interfere. We found that loading the CSV caused leading zeros to vanish.


# Filling in with zeros and truncating to 8 characters
df['student_id'] = df['student_id'].str.zfill(8).str[-8:]

Why did this happen?

The reason this issue arises is because when we load a csv file using pd.read_csv, the column "student_id", originally 10-characters long, is automatically detected as containing numerical values. The IDs are thus loaded as integers, without the leading zeros.

5. Refining the Material

We filter the grades to be between 1 and 10.


df_filtered = df[(df['grade'] >= 1) & (df['grade'] <= 10)] 

# Plot histogram
plt.figure(figsize=(10,6))
